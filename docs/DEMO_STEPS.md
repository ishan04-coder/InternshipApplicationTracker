# DEMONSTRATION STEPS

## Start

Run:

```text
run.bat
```

## 1. View applications

Choose:

```text
2
```

Explain that the displayed records are loaded from `data/applications.txt`.

## 2. Add an application

Choose:

```text
1
```

Example:

```text
Company: Accenture
Role: Java Intern
Location: Pune
Deadline: 30-09-2026
Status: 1
Notes: Applied through company website
```

## 3. Search

Choose:

```text
3
```

Search for:

```text
Java
```

## 4. Update status

Choose:

```text
4
```

Enter an application ID and select a new status.

## 5. Check deadlines

Choose:

```text
5
```

Enter:

```text
30
```

## 6. Statistics

Choose:

```text
6
```

The program shows the number of applications in each status.

## 7. Delete

Choose:

```text
7
```

Enter an application ID and confirm with `y`.

## 8. Persistence test

Exit using:

```text
8
```

Start the program again and choose option `2`.

The saved records should still be present.
